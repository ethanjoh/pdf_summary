# 📚 PDF 도서 요약 & 블로그 마크다운 생성기 (PDF Book Summarizer)

PDF 도서 파일들을 폴더 단위로 일괄 분석하여 **북커버 이미지(.jpg)**와 **SEO/AEO 최적화 블로그용 마크다운(.md)**을 자동으로 생성하는 파이썬 프로그램입니다.

OCR(텍스트 레이어)이 완료된 도서는 **PyMuPDF/pymupdf4llm을 통해 로컬에서 구조화된 마크다운 텍스트를 즉시 추출**하여 Gemini API로 전송함으로써 처리 속도를 극대화하고 토큰 소모를 최소화합니다. (텍스트 레이어가 없는 스캔본은 Gemini 비전 멀티모달 모드로 자동 폴백)

---

## 🌟 주요 기능

1. **⚡ 로컬 마크다운 추출 및 고속/저비용 AI 분석**:
   - `pymupdf4llm` 기반으로 PDF의 제목, 본문, 표, 서식을 로컬에서 즉시 마크다운으로 추출
   - 불필요한 무거운 파일 업로드 대기 시간을 없애고 순수 텍스트 토큰만 소모하여 고속 요약 지원
   - 텍스트 레이어가 없는 순수 스캔본 PDF는 Gemini Files API 비전 멀티모달 모드로 자동 전환(Fallback)

2. **폴더 단위 일괄 처리 & 스마트 스킵**:
   - 지정된 폴더 내의 모든 도서 PDF를 순차적으로 탐색 및 처리
   - 이미 마크다운 리뷰가 완성된 도서는 자동으로 감지하여 건너뛰므로(Skip), 작업 중단 후 재실행 시 중복 API 호출 방지

3. **시리즈물 자동 감지 및 통합 요약**:
   - `1권, 2권, 3권`, `(1), (2)`, `_01, _02`, `상/중/하`, `Vol.1, Vol.2` 등 동일 도서명의 시리즈물을 자동 그룹화
   - **북커버 이미지**: 첫 번째 PDF(1권)에서만 대표 커버 이미지를 추출하여 생성
   - **통합 서평 마크다운**: 시리즈 전체 권수를 종합 분석하여 하나의 완성된 서평 마크다운 문서로 요약

4. **🛡️ 무료 할당량(Quota) 보호 및 자동 모델 폴백 / 즉시 안전 종료**:
   - **일일 무료 한도(PerDay/FreeTier) 초과 대응**: 기본 모델(`gemini-3.7-flash`)의 일일 한도 소진 시 `gemini-3.6-flash`로 자동 전환하며, 모든 대체 모델의 일일 한도 소진 시 불필요한 쿨다운 대기 없이 작업을 즉시 안전하게 종료
   - **분당 토큰/요청 한도(RPM/TPM) 초과 대응**: 에러 메시지의 권장 대기 시간을 자동 파싱하여 안전하게 쿨다운 대기 후 자동 재시도 (최대 5회)
   - **404 미지원 모델 자동 감지**: 서비스가 종료된 모델 감지 시 다음 사용 가능한 대체 모델로 즉시 전환

5. **📄 대용량 PDF 자동 분할 요약 (토큰 초과 대응)**:
   - 100만 토큰(1,048,576 tokens)을 초과하는 대형 도서(`400 INVALID_ARGUMENT`) 감지 시 PyMuPDF로 페이지 기준 자동 3등분 분할
   - 파트별 핵심 내용 요약 후, 최종 통합 프롬프트를 통해 누락 없는 완성형 종합 서평 마크다운 생성

6. **첫 페이지 북커버 캡처 & 이미지 링크 안정화**:
   - PyMuPDF를 활용하여 1페이지를 선명한 고해상도(200 DPI) 경량 JPG로 추출 및 저장
   - 도서명에 포함된 공백을 `_`로 치환(`{도서명_공백제거}_cover.jpg`)하여 마크다운 뷰어/웹 플랫폼에서 이미지 링크 깨짐 현상 방지

7. **스포일러 없는 장르별 맞춤 AI 도서 요약**:
   - **소설/문학**: 결말 및 핵심 반전 스포일러 없이, 인물 갈등과 서스펜스 중심의 예고편 스타일 서평 + **등장인물 관계도 (`Mermaid` 다이어그램)**
   - **비문학/실용서**: 저자의 핵심 통찰, 프레임워크, 실사례 중심 서술 + **핵심 개념 체계도 (`Mermaid` 다이어그램)**

8. **SEO & AEO 최적화 마크다운 및 렌더링 후처리**:
   - **SEO (검색 엔진 최적화)**: 메타 타이틀(30\~50자), 메타 디스크립션(80\~150자), 추천 태그, 구조화된 H1/H2/H3 헤딩
   - **AEO (AI 답변 최적화)**: ChatGPT Search, Perplexity, Google AI Overviews 등이 바로 인용할 수 있는 핵심 Q&A (FAQ) 섹션 포함
   - **렌더링 자동 보정**:
     - **물결표 이스케이프**: 취소선(strikethrough) 오작동 방지를 위한 `\~` 자동 이스케이프
     - **볼드 공백 정규화**: `**강조** ` 뒤 공백 자동 삽입
     - **Mermaid 다이어그램 최적화**: 고시인성 테마 + 4대 구문 오류 자동 보정
     - **태그 쉼표 정규화**: 블로그 플랫폼 태그창에 바로 복사 가능한 쉼표 구분 포맷
   - 네이버 블로그, 티스토리, 워드프레스, 벨로그, 노션 등에 즉시 복사/붙여넣기 가능

## 🚀 빠른 시작 가이드

### 1. 패키지 설치
Python 3.10 이상 환경에서 의존성 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```

### 2. Google Gemini API 키 설정
`.env.example` 파일을 복사하여 `.env` 파일을 만들고 본인의 API 키를 입력합니다.
([Google AI Studio](https://aistudio.google.com/app/apikey)에서 무료로 발급 가능)

```env
GEMINI_API_KEY=AIzaSy...당신의_API_키

# 기본 입출력 폴더 설정 (선택 사항)
DEFAULT_INPUT_DIR=./sample_pdfs
DEFAULT_OUTPUT_DIR=./output
```

### 3. 프로그램 실행

#### 기본 실행 (기본 폴더 `./sample_pdfs` 내 PDF 처리)
```bash
python main.py
```

#### 특정 입력/출력 폴더 지정 실행
```bash
python main.py --input_dir "E:/내_도서_폴더" --output_dir "./output"
```

#### CLI 옵션 안내
| 옵션 | 단축키 | 기본값 | 설명 |
|------|--------|--------|------|
| `--input_dir` | `-i` | `./sample_pdfs` | PDF 파일들이 위치한 입력 폴더 경로 |
| `--output_dir` | `-o` | `./output` | 마크다운 및 이미지가 저장될 출력 폴더 경로 |
| `--dpi` | | `200` | 북커버 이미지 캡처 해상도 DPI |
| `--model` | `-m` | `gemini-3.7-flash` | 분석에 사용할 기본 Gemini 모델명 |
| `--delay` | `-d` | `35.0` | 도서 완료 후 다음 도서 작업 전 안전 쿨다운 대기 시간(초) |
| `--overwrite` | | `False` | 기존 결과물이 있어도 건너뛰지 않고 다시 생성 |
| `--source` | `-s` | `False` | PDF에서 추출한 도서 원문 마크다운 파일(`_source.md`) 저장 활성화 |

## 📁 산출물 구조 (Output)

출력 폴더(`output_dir`) 하위에 **입력 폴더명과 동일한 서브폴더**가 자동으로 생성되며, 도서별로 기본 2종(북커버, 서평 마크다운) 또는 `--source` 옵션 적용 시 원문 마크다운을 포함한 3종 파일이 저장됩니다.

```
output/
└── {입력폴더명}/
    ├── 도서제목_cover.jpg       # 1페이지 고화질 북커버 이미지
    ├── 도서제목_review.md      # Gemini AI 생성 SEO/AEO 최적화 블로그 서평 마크다운
    └── 도서제목_source.md      # (--source 옵션 시) PDF 추출 도서 원문 마크다운 전체 텍스트
```

### 생성되는 마크다운 문서 구조
```markdown
### [메타데이터 및 SEO 요약]
- **SEO Title**: [클릭을 유도하는 매력적인 헤드라인 (30\~50자)]
- **Meta Description**: [검색엔진/AI 요약용 1\~2문장 핵심 요약 (80\~150자)]
- **추천 카테고리/태그**: [장르], [핵심키워드], [추천독자층]

# [블로그 포스팅 메인 제목]
![도서제목 북커버](./도서제목_cover.jpg)

> **💡 핵심 한 줄 요약**: [책의 가장 강력한 메시지]

## 1. 📖 도서 개요 및 이 책이 주목받는 이유
## 2. 🧩 핵심 구조 및 시각적 다이어그램 (Mermaid Diagram)
## 3. 💡 핵심 내용 & 흥미진진한 탐구 (※ 스포일러 없음!)
## 4. 🔍 독서 전 미리 보는 핵심 관전 포인트 / 질문 3가지
## 5. ✨ 이 책의 독보적 매력 & 추천 대상
## 6. ❓ 자주 묻는 질문 (AEO 최적화 Q&A / FAQ)
```

## 🛠️ 기술 스택

- **언어**: Python 3.10+
- **LLM SDK / AI**: `google-genai` (Gemini 3.7 Flash, 3.6 Flash)
- **PDF 엔진 & 마크다운 추출**: 
  - `PyMuPDF` (북커버 렌더링, 메타데이터 추출, 대용량 PDF 분할)
  - `pymupdf4llm` (PDF 구조 분석 및 로컬 고품질 마크다운 텍스트 추출)
- **시각화 (다이어그램)**: `Mermaid.js` (인물 관계도 및 핵심 개념 체계도 다이어그램)
- **진행률 표시**: `tqdm`
- **환경 변수**: `python-dotenv`
- **테스트**: `unittest` (내장 단위 테스트 스위트)
